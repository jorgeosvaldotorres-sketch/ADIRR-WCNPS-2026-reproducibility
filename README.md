# ADIRR WCNPS 2026 — Reproducibility Package

This repository contains the public reproducibility package for the WCNPS 2026 study.

The package is intentionally limited to the artifacts required to reconstruct, audit, and re-run the experiment reported in the manuscript. Administrative material, manuscript drafts, and intermediate notebook versions are not included.

## Reviewer-oriented traceability

The public package allows a reviewer to identify:

1. **Which code was executed** — `notebook/ADIRR_WCNPS_2026_COLAB_v0_4.ipynb`.
2. **Which parameters were used** — documented in the protocol, factorial design, notebook, and freeze manifest.
3. **Which seeds were used** — the master seed and child-stream policy are documented in the protocol and freeze manifest.
4. **Which environments and dependencies were validated** — see `reproducibility/ENVIRONMENT.md`.
5. **Which result files support Table 3 and the quantitative claims** — see the CSV and result-summary files under `results/`.

## Frozen scientific execution

- Frozen notebook: `ADIRR_WCNPS_2026_COLAB_v0_4.ipynb`

- Observability levels: `q = {1.00, 0.80, 0.60, 0.40}`
- Pilot replications: `R = 100`
- Scientific replications: `R = 2000`
- Experimental conditions: 24

## Repository structure

- `protocol/` — experimental protocol, factorial design, and D3/D4/D6 operationalization.
- `notebook/` — frozen notebook used for the scientific execution.
- `results/` — pilot results, scientific aggregates, paired differences, and per-replication results.
- `reproducibility/` — freeze manifest and validated software environments.

## Main result files

- `results/execucao_cientifica_metricas_finais.csv` — DMA, MAE, DP-Rep, and MCSE by method, q, and L.
- `results/execucao_cientifica_delta_pareado.csv` — paired M2−M1 differences and MCSE.
- `results/execucao_cientifica_per_replicacao.csv` — per-replication values used to reconstruct the reported aggregates.
- `results/piloto_tecnico_100rep_resumo.csv` — pilot summary across the 24 conditions.

## Reproduction

1. Open the frozen notebook in Google Colab or a compatible Python environment.
2. Use the frozen configuration documented in the notebook and protocol.
3. Run the pilot configuration first if engineering validation is desired.
4. Run the scientific configuration with `scientific_replications = 2000`.
5. Compare generated outputs with the files under `results/`.

The experiment uses synthetic data generated by the notebook itself; no external or private dataset is required.

## Scope

This package supports the controlled stationary cooperative-agent experiment reported in the manuscript. It does not cover future extensions involving malicious agents, on-off behavior, D5 revision mechanisms, richer provenance, or coordinated attacks.
